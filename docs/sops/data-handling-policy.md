# Data Handling Policy

## Classification
Customer data is confidential. Aggregated metrics with no customer identifiers
are internal. Salary and compensation data is restricted to HR.

## Retention
Support tickets are retained for 24 months, then anonymized. Email threads
are retained for 12 months. Backups follow the same schedule.

## Access
Access follows role-based policies enforced at query time. Denied access is
logged with the policy ID that blocked it.
